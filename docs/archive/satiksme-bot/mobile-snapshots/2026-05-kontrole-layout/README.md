# Kontrole Mobile Layout Snapshots

Accessibility-tree snapshots captured while checking Kontrole public map and incident mobile layouts. These are archived layout snapshot material, not active root context.

## Files

- `kontrole-root-mobile-snapshot.md`: desktop-width map snapshot baseline.
- `kontrole-root-mobile390-snapshot.md`: 390 px mobile map snapshot baseline.
- `kontrole-root-mobile390-afterresize-snapshot.md`: 390 px map snapshot after resize.
- `kontrole-incidents-mobile390-snapshot.md`: 390 px incident feed snapshot.

Keep future raw browser snapshots under timestamped evidence folders when they do not need to be tracked, or under `docs/archive/` when the snapshot is kept as a durable docs artifact and link only concise findings back into service docs.
